# CYBER-DOME: Neon Automata (サイバー・ドーム: ネオン・オートマタ)

CYBER-DOME: Neon Automata は、商用レベルのクオリティを誇る、サイバーパンクの世界観を持ったデッキ構築＆バトルシミュレーション・トーナメントゲームです。Go標準ライブラリとWebSocketで構築された超軽量・高速なリアルタイム・バックエンドと、React + TypeScript + Tailwind CSS v4で実装された美麗なフロントエンドUI/UXを特徴としています。

---

## 🎮 ゲームデザインとコアメカニクス

全7ラウンドで構成されるトーナメント戦です。プレイヤーは10クレジットを持ってゲームを開始し、他の戦闘員（人間またはNPC）と勝ち点およびファン（支持者）数を競い合います。

### 🔌 メモリオフロー・バトルエンジン（サーバーサイド対戦）
バトルはメインフレームへの「アクセス権（フラッグ）」を奪い合う、独自のカードめくり対戦システムです。
1. **フラッグの奪還**: 対戦者同士がデッキトップから交互にカードをめくります。チャレンジャー側は、現在フラッグを保持しているカードの合計パワー以上のカードをめくるとフラッグを奪取できます（同値でも奪取成功です）。
2. **メモリ退避（ベンチ）**: フラッグを奪取された側のカードは敗北し、「メモリスロット（ベンチ）」へと送られます。
3. **同名カードのスタック**: メモリスロットは**最大6スロット**です。ただし、【同名のカードは同じスロットに累積（スタック）】され、新しいスロットを消費しません。
4. **メモリオーバーフロー（敗北）**: ベンチに退避されたカードが「7種類目」に達した瞬間、メモリオーバーフローを起こしてそのプレイヤーは即座に敗北します。また、フラッグを奪い返す前に山札（ソースコード）が尽きた場合も敗北となります。

### 🧬 カード属性と3つのアーキタイプ（全24種類のプログラム）
カードには4つの属性（Virus、AI、Hardware、Netrunner）と3つのシナジー（アーキタイプ）を持たせています。
1. **アグロ・グリッチ（Virus属性）**: 相手のパワーを直接減少させたり、相手の山札をデリート（廃棄）する短期決戦型。
2. **コンボ・スタック（AI属性）**: メモリスロットのAIカードの枚数に応じてパワーが何倍にも強化される相乗効果型。
3. **コントロール・最適化（Hardware / Netrunner属性）**: ロック機能、RAM節約機能、味方全体のバフなどの耐久管理型。

## 🌐 オンラインマルチプレイヤーロビー（新規追加）

本機能はブランチ `feature/multiplayer-lobby` にて完全にコンテナ最適化され実装されています。

1. **リアルタイムロビー同期**: WebSocket通信を搭載したアリーナ作成/参加機能。チャットターミナルで対戦相手との連携も可能です。
2. **柔軟な対戦枠（3〜8名）**: 3人から8人までの任意の人数でプレイ可能です。足りない枠はインテリジェントNPCで自動または手動でバックフィル（補填）できます。
3. **総当たりマッチメイク（Berger Tables）**: ラウンドロビン（総当たり）方式のアルゴリズムを内蔵。奇数プレイヤー時には「BYE（不戦勝）」が割り当てられ、不戦勝者は自動的に +1勝、+1ファンを獲得します。
4. **対称型NPCショップAI**: NPCは人間と同じ10クレジット（持越し可）を使って、自らの戦略（アグロ/コンボ/コントロール）に基づいてカードの購入、リロール、および不要カードの削除を完全に自律的に行い、ゲームバランスを極限まで引き上げます。
5. **切断時自動再同期 (Auto-Resync)**: 接続が切れても、再接続成功時に自動で最新のセッション状態に引き込まれ、 desync が防止されます。
6. **ホストキック / NPC代替機能**: ホストはロビーからNPCを自在に削除できるだけでなく、対戦中に無反応になったプレイヤーをNPCに即時変換してトーナメントをノンストップで継続できます。

## 🛠️ 技術スタックとアーキテクチャ

- **バックエンド**: Go 1.26 (外部ライブラリ依存は `gorilla/websocket` のみ)。排他制御（Mutex）によるスレッド安全インメモリ状態管理。
- **フロントエンド**: React 19 + TypeScript + Tailwind CSS v4 + Vite。ダークメタリック背景に輝くネオン、タイムラインエンジンを搭載。
- **コンテナ環境**: Docker Compose によるフロントエンド・バックエンドの完全コンテナ化。

---

## 🚀 開発環境でのクイックスタート（Docker Compose）

コンテナ環境での動作確認が最も推奨される方法です。

### 1. サービスのビルドと立ち上げ
```bash
docker-compose up --build
```
このコマンドにより、バックエンドの Go サーバーとフロントエンドの React/Vite サーバーがそれぞれ自動で立ち上がります。

### 2. ポートアクセス
- **🎮 ゲームUI (フロント):** [http://localhost:5173](http://localhost:5173)
- **🔌 API ゲートウェイ (バック):** [http://localhost:8080](http://localhost:8080)

複数のブラウザタブまたはシークレットウィンドウを開き、名前を入力して「Create Arena / Join Arena」よりマルチプレイ対戦の滑らかな同期をご体験ください！

## 💻 マニュアルでのローカル起動

### 1. バックエンドサーバーの起動
```bash
cd backend
go mod tidy
go run main.go
```

### 2. フロントエンドの開発サーバー起動
```bash
cd frontend
npm install
npm run dev
```
Viteサーバーが起動し、ブラウザで [http://localhost:5173](http://localhost:5173) にアクセス可能です。
