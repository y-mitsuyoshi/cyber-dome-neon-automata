# CYBER-DOME: Neon Automata (サイバー・ドーム: ネオン・オートマタ)

CYBER-DOME: Neon Automata は、商用レベルのクオリティを誇る、サイバーパンクの世界観を持ったデッキ構築＆バトルシミュレーション・トーナメントゲームです。Go標準ライブラリで構築された超軽量・高速なバックエンドと、React + TypeScript + Tailwind CSS v4で実装された美麗なフロントエンドUI/UXを特徴としています。

---

## 🎮 ゲームデザインとコアメカニクス

全7ラウンドで構成されるトーナメント戦です。プレイヤーは10クレジットを持ってゲームを開始し、他の7名のNPC combatantと勝ち点およびファン（支持者）数を競い合います。

### 🔌 メモリオフロー・バトルエンジン（サーバーサイド対戦）
バトルはメインフレームへの「アクセス権（フラッグ）」を奪い合う、独自のカードめくり対戦システムです。
1. **フラッグの奪還**: 対戦者同士がデッキトップから交互にカードをめくります。チャレンジャー側は、現在フラッグを保持しているカードの合計パワーを上回るまでカードをめくり続ける必要があります。
2. **メモリ退避（ベンチ）**: フラッグを奪取された側のカードは敗北し、「メモリスロット（ベンチ）」へと送られます。
3. **同名カードのスタック**: メモリスロットは**最大6スロット**です。ただし、【同名のカードは同じスロットに累積（スタック）】され、新しいスロットを消費しません。
4. **メモリオーバーフロー（敗北）**: ベンチに退避されたカードが「7種類目」に達した瞬間、メモリオーバーフローを起こしてそのプレイヤーは即座に敗北します。また、フラッグを奪い返す前に山札（ソースコード）が尽きた場合も敗北となります。

### 🧬 カード属性と3つのアーキタイプ（全24種類のプログラム）
脳死でスタッツの高いカードを集める単調な戦略を壊すため、カードには4つの属性（Virus、AI、Hardware、Netrunner）と3つのシナジー（アーキタイプ）を持たせています。
1. **アグロ・グリッチ（Virus属性）**: 相手のパワーを直接減少させたり、フラッグを奪った瞬間に相手の山札を直接デリート（強制廃棄）する短期決戦型（例: `Data Leech`）。
2. **コンボ・スタック（AI属性）**: メモリスロットのAIカードの枚数に応じてパワーが何倍にも強化される相乗効果型（例: `Neural Stack`）。
3. **コントロール・最適化（Hardware / Netrunner属性）**: ロック機能、20%の確率でメモリスロットを消費しないRAM節約機能、味方全体のバフなどの耐久管理型（例: `Firewall Prime`）。

## 🛠️ 技術スタックとアーキテクチャ

- **バックエンド**: Go 1.22 (外部ライブラリ依存ゼロ)。標準パッケージ `net/http` のみによる超高速ルーター、CORS制御、および排他制御（Mutex）によるインメモリ状態管理。
- **フロントエンド**: React 19 + TypeScript + Tailwind CSS v4 + Vite。ダークメタリックな背景（`bg-slate-950`）に輝くネオンシアンとネオンマゼンタのグラデーション、ノイズ/グリッチ演出、およびバトルの時系列ログを視覚的に手動/自動再生するタイムラインエンジンを搭載。
- **環境構築**: Docker Compose によるフロントエンド・バックエンドの完全コンテナ化。

## 🚀 開発環境でのクイックスタート（ローカル起動）

### 前提条件
- Go 1.22 以上（バックエンド用）
- Node.js 20 以上（フロントエンド用）

### 1. バックエンドサーバーの起動
```bash
cd backend
go run main.go
```
`http://localhost:8080` でバックエンドが起動し、以下の結合APIが解放されます。
- `POST /api/game/new`
- `GET /api/game/state?gameId=XXX`
- `GET /api/shop?gameId=XXX`
- `POST /api/shop/buy`
- `POST /api/shop/reroll`
- `POST /api/shop/delete`
- `POST /api/tournament/battle`
- `POST /api/tournament/next-round`

### 2. フロントエンドの開発サーバー起動
```bash
cd frontend
npm install
npm run dev
```
ブラウザで `http://localhost:5173` にアクセスし、サイバー・ドームへジャックインしてください！
